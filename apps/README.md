# Olegshifter — приложения

GUI-клиент и web-сервер поверх ядра из `core/`.

## Установка

```bash
pip install -r apps/requirements.txt
```

## Клиент (GUI с треем)

```bash
python apps/client_gui.py
```

Что делает:
- Окно настроек: адрес сервера, кол-во каналов, preshared/DH secrets, TLS, SOCKS5 порт.
- Кнопка **Подключить / Отключить**.
- Цветные индикаторы каналов (зелёный = жив, красный = упал).
- Иконка в трее (жёлто-серый = отключено, зелёный = работает).
- Конфиг: `~/.olegshifter/client.json`.

После подключения настрой браузер на `SOCKS5 127.0.0.1:1080`
(или какой порт ты указал).

## Сервер (web UI)

```bash
python apps/server_web.py
```

Открой `http://127.0.0.1:7070/login?token=<ТОКЕН>` — токен печатается в консоль при старте.

Что можно:
- Стартовать / останавливать слушатель каналов прямо из браузера.
- Видеть подключённых клиентов и сколько каналов у каждого.
- Редактировать конфиг (применяется при следующем запуске).
- Читать лог в реальном времени.

Конфиг: `~/.olegshifter/server.json`.
Токен: генерится автоматически при первом запуске, хранится там же.
По умолчанию web UI слушает только `127.0.0.1`.
Если нужен удалённый доступ — поменяй `web_host` на `0.0.0.0` и проброс делай через SSH-тоннель или фронтовой nginx с HTTPS.

## Секреты

`preshared`, `dh_secret`, `salt` — должны совпадать на клиенте и сервере.
Пример выше — заглушки, замени на реальные (рекомендую 32 байта каждого):

```python
import secrets
print(secrets.token_urlsafe(32))
```
